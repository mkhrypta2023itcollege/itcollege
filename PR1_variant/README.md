# Італія в деталях

Практична робота №1: простий багатосторінковий сайт про подорож до Італії.

## Сторінки

- `index.html` — головна сторінка з картками міст, таблицею та відео;
- `rome.html` — Рим;
- `florence.html` — Флоренція;
- `venice.html` — Венеція;
- `gallery.html` — фотогалерея;
- `contact.html` — форма зворотного зв'язку та підписки.

## Технології

HTML5, CSS3. Без JavaScript.
